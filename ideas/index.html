核心观点

本体定义世界，事实反映世界，知识解释世界，规则约束行动。这是罗忠富给公益慈善行业数字化与AI建设的基本公式。

慈善数字化

从建设系统，转向建设可被AI理解的数字世界。

本体

先定义对象、关系与规则，再选择系统和模型。

事实中心

数据中心要保存的是组织事实，而不是孤立字段。

知识中心

制度、案例、经验必须对象化，不能只做文档库。

规则中心

知识负责理解，规则负责执行。可信AI依赖规则层。

AI Agent

Agent 不是聊天窗口，必须接本体、事实、知识、规则与权限。

Workflow

流程可以不变，但节点必须变智能，并留下人机协同证据。
